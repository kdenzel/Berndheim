# Small Gameboy-Demo that plays the german song "Erika"

It can be played on a GB/GBA emulator or on original Hardware.

It is implied that the rgbasm tool (see https://rgbds.gbdev.io/) is installed and working on your machine.

Depends on the GfxTool (see https://github.com/kdenzel/GfxTool). The Path must be relative to ${ProjectDir}../tools/gfx.jar.
